# LunaWake 科学信任传播资产包

这套资产围绕一个核心原则组织：

> 科学依据清楚解释，产品机制具体展示，实验方法公开到可公开的程度，产品边界主动说明。

## 已交付

- `LunaWake-science-principles.md`：官网科学原理页的完整中文底稿。
- `LunaWake-science-evidence-map.pdf`：一页科学证据地图。
- `LunaWake-science-brief-template.pdf`：每个实验一页的研究摘要模板。
- `LunaWake-principle-cards.pdf`：睡眠行为、光线、声音、非接触感知四张原理卡。
- `LunaWake-science-faq.pdf`：科学 FAQ 与声明手册。
- `LunaWake-packaging-foldout.pdf`：包装内两页“为什么这样设计”折页。
- `science-page-copy.md`：官网 Science 页面中文内容底稿。
- `research-brief-template.md`：研究项目摘要可编辑文字模板。
- `science-faq.md`：FAQ 可编辑文字版本。

## 需要上线前补齐的事实

1. 合作高校/实验室的正式名称与公开授权。
2. 每个研究项目的样本量、纳入条件、实验流程、测量指标和结果。
3. 对外照片的人像、场地、设备和合作方使用授权。
4. 对“CBT-I、光线、声音”具体表述的医学与广告合规复核。

当前所有未确认事实均使用“验证进行中”“待授权”“待补录”表达，没有将实验现场照片当作产品疗效证明。
