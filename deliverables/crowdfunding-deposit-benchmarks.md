# 众筹订金页 / 预发布页高转化案例库

> 研究日期：2026-08-04
>
> 用途：为 LunaWake `$9` 订金页提供可验证的众筹、预留订金和预发布页面参考。
>
> 说明：行业没有公开、统一、可横向比较的“历史最高订金页转化率”榜单。本库按“公开转化率证据 > 公开订金规模 > 公开募资结果但无订金率”排序，避免把募资额直接当作订金页转化率。页面素材只做结构和视觉研究，不镜像第三方整页或受版权保护的图片。

## 1. 快速结论

最值得借鉴的不是某一个页面模板，而是一条重复出现的决策链：

```text
一张能让人想象使用场景的主视觉
→ 一句话说清“谁在什么场景得到什么结果”
→ 明确价格窗口 / 节省金额 / 订金含义
→ 1 个主 CTA，后续在高意向段落重复
→ 产品证据（实拍、演示、对比、创始人）
→ 风险和退款边界
→ 下一步时间线与通知机制
```

Prelaunch 的公开帮助文档把预留页的最小信息定义为：产品价、折后价、订金金额；订金通常是产品价格的 1–5%，并且上线前可取消退款。[Reservation Deposit 规则](https://help.prelaunch.com/en/articles/8263057-what-is-a-reservation-deposit) / [Reservation Funnel](https://help.prelaunch.com/en/articles/8232392-how-does-the-reservation-funnel-work)

Prelaunch 给出的粗略基准是：售价低于 `$500` 的产品，访问者→订金预留约 2%；高价产品约 1%；订阅→订金约 15%。这只是平台经验值，不是全行业标准。[Product Launch Metrics](https://prelaunch.com/blog/product-launch-metrics)

## 3. 页面设计拆解

### 3.1 Blisstil：最贴近 LunaWake 的首屏

首屏可观察到的结构：

- 深色背景，左侧大幅睡眠场景图，右侧短句价值承诺。
- 文案不是功能清单，而是“侧睡时软、能降噪、能听高保真、还有颈部支撑”的场景化组合。
- 一个高对比按钮 `Order Now >>`，不让用户先读长篇品牌故事。
- 产品证据放在首屏视觉里：人在床上真实使用，而不是只展示孤立产品渲染图。

可借给 LunaWake：使用卧室 / 床边 / 起床后的生活场景作为第一视觉；首屏只保留三个主卖点：理解夜间模式、自动配合、不用佩戴。科学、隐私和完整机制下移为信任证明。

### 3.2 Circular Ring 2：结果 + 产品规格 + 价格卡

可观察到的结构：

- 主视觉同时呈现人物佩戴、产品近景和多色选择。
- 副标题把“心律、AI 洞察、140+ 生物指标、无订阅、7 天续航、轻量”压成一行，快速建立产品类别和价值密度。
- 右侧 reward 卡直接显示档位名、价格、节省金额和购买描述。
- 页面导航把活动、回报、FAQ、更新、评论拆开，降低长页面寻找信息的成本。

可借给 LunaWake：把 `Founding Backer Reward / $229 / Save $150 / $9 today` 做成右侧固定决策卡；五色展示可以作为产品选择的视觉证据，但必须明确“订金不锁色、不锁 SKU”。

### 3.3 Sea Beasts：先让用户想象，再给参数

官方复盘披露的结构是：先用主题世界、情绪和故事让用户判断“这是不是我的产品”，之后才进入组件、玩法和参数；CTA 分布在用户兴趣峰值处，而不是只放首尾。

可借给 LunaWake：先用“Read your night”建立使用想象，再讲自动调节和免佩戴；不要在首屏塞进完整技术原理、隐私规则和 FAQ。规则要前置，但要用一张清晰的规则卡承载。

### 3.4 FUELL Fllow：订金真正买到什么

Fllow 的高承诺设计不是只写“抢先加入名单”，而是把订金和可感知的经济利益绑定：明确订金、未来优惠额、赠品、颜色 / 版本 / 价格测试以及社群反馈。它把订金从“留资”变成了一个小型交易。

可借给 LunaWake：`$9` 必须同时看到当前 Reward 价格、零售价差额、退款时点、Kickstarter 下一步和 coaching 资格；但不要声称 `$9` 直接抵扣 Kickstarter 付款，除非业务链路真的支持。

### 3.5 Prologue by NIDA：两步漏斗比一张长页更适合高解释成本

这个案例先用简单订阅收集兴趣，再把经过解释和筛选的人带到 `$1` 预留页，随后让预留者完成资格问卷。公开数字说明第二步用户质量显著高于第一步泛兴趣人群。

可借给 LunaWake：广告冷流量和已完成前测的 Leads 不应使用同一个解释强度。已完成前测的用户可以直达 `$9` 订金页；冷流量则应先看到“什么是 Kickstarter、$9 到底买什么、什么时候能退”的简化教育层。

```text
┌──────────────────────────────────────────────┐
│ [卧室生活场景 + LunaWake 产品]                │
│ Read your night. Wake up to a room that fits. │
│ Understand your night / Adjusts for you /     │
│ No wearable                                  │
│                                              │
│ Founding Backer Reward  $229                 │
│ Save $150 vs. $379 retail                    │
│ $9 today · paid through Shopify              │
│ [Lock in $229 access — $9]                   │
│ Fully refundable before Kickstarter launches │
└──────────────────────────────────────────────┘

1. What the $9 means
   Shopify 订金 → Kickstarter 专属链接 → 有效 pledge → coaching

2. Refund / no-refund rules
   上线前可退；众筹失败/取消可退；上线后未 pledge 不退

3. Three price windows
   当前档位突出，已结束 / Upcoming 明确标记

4. Five finishes
   五色一起展示；不默认选色；支付后确认偏好

5. Three product proofs
   Read your night / Adjusts for you / No wearable

6. Trust layer
   No camera / raw signals stay on device / physical privacy gate

7. FAQ + support
   邮箱匹配、时间线、退款、发货、Kickstarter 规则
```

## 5. 页面实验优先级

| 优先级 | 实验 | 对照变量 | 成功指标 |
|---|---|---|---|
| P0 | 首屏主视觉 | 卧室人物场景 vs. 产品静物 | `$9` 支付完成率，不只看 CTA 点击 |
| P0 | 首屏主标题 | `Read your night` vs. `Wake up to a room that fits` | 首屏到 CTA 点击、支付完成率 |
| P0 | 规则承载方式 | 首屏短规则卡 vs. 首屏仅一句摘要 + 下方完整规则 | 规则相关客服问题、支付完成率、退款率 |
| P1 | 价格锚点 | `$229 / Save $150` vs. 只展示 `$229` | 支付完成率、退款率 |
| P1 | 订金解释 | 三步流程卡 vs. 单句解释 | 结账流失、邮箱匹配错误 |
| P1 | 产品证明顺序 | 场景 → 机制 → 隐私 vs. 机制 → 场景 → 隐私 | 支付完成率、页面滚动深度 |
| P2 | CTA 文案 | `Lock in $229 access — $9` vs. `Reserve for $9` | CTA 点击 / 支付完成率 |

不要用同一时间段的自然流量直接替代 A/B 测试；价格、退款规则、Kickstarter Reward 配置必须固定版本并记录发布时间。

## 6. 研究边界与使用原则

- 公开案例常披露募资额、支持者数、广告到落地页转化，却很少披露“订金页访问→订金支付”的完整分母。因此本库不宣称存在一个可证实的“历史第一”。
- Kickstarter 的预发布页本身主要目标是 `Notify me on launch`，桌面端包含标题、副标题、主图、类别、地点、描述、创作者和更新；它和独立 Shopify 订金页不是同一种页面。[Kickstarter 预发布页规则](https://help.kickstarter.com/hc/en-us/articles/360034769114-Setting-up-your-project-s-pre-launch-page)
- 订金页要学习结构、信息层级和视觉逻辑，不直接复制第三方图片、视频、文案、品牌标识或页面代码。
- 对 LunaWake，订金语义、退款规则、邮箱匹配和 Kickstarter 二次支付必须优先于“制造稀缺感”。任何未经 agency / Shopify / 法务确认的库存、Reward 或退款承诺不得放进页面。
